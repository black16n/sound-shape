# 光，替我听见（声音的形状）

> 给听不见的人，做一盏「认得出声音」的灯——**你教它认什么，它就用光告诉你什么来了。**

一款基于**声纹识别**的无障碍装置。门铃响、水烧开、有人敲门，它会把这些声音实时翻译成灯光的颜色与闪烁，让听障人士「抬头就能看见」，而不是低头去点开一条手机通知。

- 首届郑轻中源黑客松参赛作品
- 定位：**软硬结合** —— ESP32 硬件独立识别（主角）+ 网页可视化大屏（镜子）

---

## 核心特点

| 特点 | 说明 |
|---|---|
| 🎯 认出声音身份 | 不是「音量灯」——不会只亮，而是告诉你**是哪种声音** |
| 🏠 家庭声纹学习 | 长按按键录几次，盒子学会**你家的门铃**，只认你家的 |
| 🔒 纯本地离线 | 不上云、不调大模型、声音不出家门，隐私安全 |
| 💰 极低成本 | 一块 ESP32（十几块）+ 麦克风 + OLED + 灯 |

## 快速开始

### 方式一：仅前端演示（最简单，无需 Python、无需硬件）

双击 `sound_shape/open_standalone.bat`，浏览器直接打开大屏。
麦克风 + 本地规则识别即可跑通，适合路演投屏。

### 方式二：完整软硬链路（三个窗口）

```
1) 双击 sound_shape/start_server.bat   → http://127.0.0.1:5000
2) 双击 sound_shape/start_bridge.bat   → 选串口（先关 Arduino 串口监视器）
3) 浏览器打开 http://127.0.0.1:5000/
```

> 链路不通时双击 `sound_shape/check_link.bat`，五段式体检会告诉你断在哪一段。

### 硬件（ESP32）

- 固件：`sound_shape/sound_shape_fw.ino`
- 接线（见固件文件头注释）：INMP441(SCK→IO4, WS→IO5, SD→IO6)、按键(IO10)、OLED(SDA→IO9, SCL→IO8)
- 依赖库：**U8g2**（Arduino 库管理器搜索安装）
- 烧录前记得在固件顶部填入你的 `WIFI_SSID` / `WIFI_PASS`（不填则离线运行，显示开机时长）

## 识别原理

采用**模板匹配**（比相似度），而非深度学习：

1. 麦克风采集 → FFT 频谱
2. 提取频谱特征（频带能量比，硬件 12 频带 / 后端 20 维）
3. 与已存模板逐个算相似度（L1 距离 / 余弦）
4. 最高分超过阈值且领先第二名足够多 → 触发

用户训练（长按按键 3 秒进入）：录几秒声音 → 取「最响几帧」的平均做模板 → 存 NVS，断电不丢。

## 技术栈

| 层 | 技术 |
|---|---|
| 硬件 | ESP32、INMP441(I²S)、0.96 OLED(U8g2)、三色 LED |
| 固件 | Arduino、自定义 512 点 FFT、12 频带声纹、Preferences(NVS) |
| 后端 | Python 标准库（零 pip 依赖）、SQLite、WebSocket/SSE |
| 前端 | 原生 HTML/CSS/JS（单文件）、Web Audio API、Canvas |
