## 二、可复用代码模块（按功能拆）

### 模块 1：I²S 麦克风采样（INMP441）

**参考来源**：ESP32 I²S 标准驱动 + INMP441 官方接法（通用技术）

**干什么**：以 16kHz 采样率持续采集音频，输出 PCM 数据。

```cpp
#include <driver/i2s.h>

#define I2S_WS   4   // LRC
#define I2S_SCK  5   // BCLK
#define I2S_SD   6   // DOUT

void initMic() {
  i2s_config_t cfg = {
    .mode = (i2s_mode_t)(I2S_MODE_MASTER | I2S_MODE_RX),
    .sample_rate = 16000,
    .bits_per_sample = I2S_BITS_PER_SAMPLE_32BIT,
    .channel_format = I2S_CHANNEL_FMT_ONLY_LEFT,
    .communication_format = I2S_COMM_FORMAT_STAND_I2S,
    .intr_alloc_flags = ESP_INTR_FLAG_LEVEL1,
    .dma_buf_count = 4,
    .dma_buf_len = 256,
  };
  i2s_pin_config_t pins = {
    .bck_io_num = I2S_SCK,
    .ws_io_num = I2S_WS,
    .data_out_num = I2S_PIN_NO_CHANGE,
    .data_in_num = I2S_SD,
  };
  i2s_driver_install(I2S_NUM_0, &cfg, 0, NULL);
  i2s_set_pin(I2S_NUM_0, &pins);
}

// 读取一段采样
void readSamples(int32_t* buf, int n) {
  size_t bytesRead = 0;
  i2s_read(I2S_NUM_0, buf, n * sizeof(int32_t), &bytesRead, portMAX_DELAY);
}
```

**要点**：INMP441 是 I²S 输出，接 SCK/WS/SD 三根数据线 + 3.3V + GND。16kHz 采样对门铃/水开/人声足够。

### 模块 2：FFT 频谱分析

**参考来源**：`arduinoFFT` 库（通用，MIT 协议，人人可用）+ soundAlert 项目的用法思路

**干什么**：把时域音频转成频域，拿到"哪些频率强"。

```cpp
#include <arduinoFFT.h>

arduinoFFT FFT = arduinoFFT();
#define SAMPLES 256
double vReal[SAMPLES];
double vImag[SAMPLES];

void doFFT(int32_t* raw, int n) {
  for (int i = 0; i < SAMPLES; i++) {
    vReal[i] = raw[i];  // 取实部
    vImag[i] = 0;
  }
  FFT.Windowing(FFT_WIN_TYP_HAMMING, FFT_FORWARD);
  FFT.Compute(FFT_FORWARD);
  FFT.ComplexToMagnitude();
  // 现在 vReal[i] 就是第 i 个频点的幅度
}
```

**要点**：这是"检测到声音"的通用做法，任何人都能用。**但"这个频谱对应敲门还是水开"的判断规则，是你们要自己写的。**

### 模块 3：峰值频率 / 能量比 / 节奏提取（自己写，但算法通用）

**干什么**：从 FFT 结果里提取三个特征——这是"声纹指纹"的基础。

```cpp
// 1. 峰值频率：找能量最大的频点
float peakFrequency(double* mag, int n, int sampleRate) {
  int peakIdx = 0;
  double maxVal = 0;
  for (int i = 1; i < n / 2; i++) {
    if (mag[i] > maxVal) { maxVal = mag[i]; peakIdx = i; }
  }
  return (float)peakIdx * sampleRate / n;  // 换算成 Hz
}

// 2. 能量比：低频 vs 高频能量占比
float energyRatio(double* mag, int n) {
  double low = 0, high = 0;
  for (int i = 0; i < n / 2; i++) {
    double e = mag[i] * mag[i];
    if (i < n / 4) low += e;  // 低频段
    else high += e;           // 高频段
  }
  return low / (low + high);  // 0~1，越大越偏低频
}

// 3. 节奏：数 onset（声音起始点）次数和间隔
int countOnsets(double* mag, int n, int threshold) {
  // 简化：统计能量超过阈值的"段"数量
  int beats = 0;
  bool prev = false;
  for (int i = 0; i < n; i++) {
    bool cur = mag[i] > threshold;
    if (cur && !prev) beats++;  // 上升沿计数
    prev = cur;
  }
  return beats;
}
```

**要点**：这三个函数是**通用信号处理**，思路公开，但组合成"敲门=短促三连、水开=持续高频、人声=85-255Hz"这套**判断规则是你们的原创**。

### 模块 4：OLED 显示

**参考来源**：U8g2 库（通用）

**干什么**：显示"敲门/水开了/有人喊你"文字 + 用刷新节奏模拟"颜色"。

```cpp
#include <U8g2lib.h>
U8G2_SSD1306_128X64_NONAME_F_HW_I2C u8g2(U8G2_R0, /*reset=*/U8X8_PIN_NONE);

void showAlert(const char* text, int flashTimes, int delayMs) {
  for (int i = 0; i < flashTimes; i++) {
    u8g2.clearBuffer();
    u8g2.setFont(u8g2_font_ncenB14_tr);
    u8g2.drawStr(10, 40, text);
    u8g2.sendBuffer();
    delay(delayMs);
    u8g2.clearBuffer();
    u8g2.sendBuffer();
    delay(delayMs);
  }
}
```

**要点**：0.96 OLED 是单色屏（通常白或蓝），**没有真彩色**。所以"门铃蓝、水开橘、喊你白"要用**闪烁节奏**代替颜色：
- 敲门 = 快闪 3 下
- 水开 = 持续脉动
- 喊你 = 突然全亮

（如果能领到 WS2812 灯带，就用 FastLED 实现真彩色，优先级更高）

### 模块 5：按键（长按 10 秒学习）

**参考来源**：通用按键检测（millis 计时）

```cpp
#define BTN_PIN 0  // 按键接 GPIO0（内部上拉）

void checkButton() {
  static unsigned long pressStart = 0;
  static bool pressing = false;

  if (digitalRead(BTN_PIN) == LOW) {  // 按下（接地）
    if (!pressing) {
      pressing = true;
      pressStart = millis();
    }
    if (millis() - pressStart > 10000) {  // 长按 10 秒
      learnDoorbell();  // 进入"学习门铃"流程
      pressStart = millis();  // 重置，避免重复触发
    }
  } else {
    pressing = false;
  }
}
```

**要点**：这是通用按键逻辑。**"长按 10 秒 → 学习你家门铃 → 存指纹"这个产品流程是你们的原创卖点。**

### 模块 6：指纹存储（EEPROM / NVS，断电不丢）

**参考来源**：ESP32 NVS / Preferences 库（通用）

```cpp
#include <Preferences.h>
Preferences prefs;

void saveFingerprint(float freq, float ratio, int beats) {
  prefs.begin("doorbell", false);
  prefs.putFloat("freq", freq);
  prefs.putFloat("ratio", ratio);
  prefs.putInt("beats", beats);
  prefs.end();
}

void loadFingerprint(float& freq, float& ratio, int& beats) {
  prefs.begin("doorbell", true);
  freq = prefs.getFloat("freq", 0);
  ratio = prefs.getFloat("ratio", 0);
  beats = prefs.getInt("beats", 0);
  prefs.end();
}
```

**要点**：用 Preferences（NVS）存指纹，比 EEPROM 更稳、容量更大，掉电不丢。
